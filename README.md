# InvestorEngine — Gate-First Investor Search (v0.1)

This is Piece 1: a **Gate UI** where **all criteria are editable**. Upload listings,
tune thresholds live, and the app returns **PASS / FAIL** with reasons for each listing.

Next pieces we can add:
- Scoring of survivors
- Evidence pack builder (assessor/permits/evictions links)
- DSCR & IRR stress testing
- Saved searches & persistence (DuckDB)
- Market/MSA public-data enrichment

## Run (cloud-friendly)
- Push to GitHub → Deploy on Streamlit Cloud → `app.py`
